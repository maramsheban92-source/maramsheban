# maramsheban

## Quiz Application

A simple command-line quiz game with multiple-choice questions.

### How to Run

Make sure you have Python 3 installed on your system. Then run:

```bash
python3 quiz.py
```

or make it executable and run directly:

```bash
chmod +x quiz.py
./quiz.py
```

### How to Play

1. The quiz will present you with multiple-choice questions
2. Enter the letter (A, B, C, or D) corresponding to your answer
3. After all questions are answered, you'll see your final score
4. Press Ctrl+C at any time to exit the quiz

### Features

- 5 multiple-choice questions covering various topics
- Immediate feedback after each answer
- Final score with percentage calculation
- Encouraging messages based on performance
